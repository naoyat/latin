# 古文（作りかけ）

平安の和文（学校の古文: 竹取物語・伊勢物語・土佐日記・枕草子・源氏物語・徒然草など）を品詞分解し、助動詞の意味・
活用の種類と活用形・係り結びを示して、現代語に組み立て直します。ほかの言語と違って共通の解析器（格の枠）は通さず、
形態素解析の結果から直接、現代語の文を作ります。

形態素解析は MeCab と国立国語研究所の [中古和文UniDic](https://clrd.ninjal.ac.jp/unidic/)（CC BY-NC-SA 4.0。非営利なら
利用可、成果には利用の明記が必要）。辞書は各自で入手してデータの置き場所に置きます（リポジトリには入れない）:

```
mkdir -p ~/.local/share/dragoman-data/ojp && cd ~/.local/share/dragoman-data/ojp
curl -L -O https://clrd.ninjal.ac.jp/unidic_archive/2512/unidic-chuko-v202512.zip      # 約195MB
unzip unidic-chuko-v202512.zip -d unidic-chuko
cd - && ./dragoman.py kobun samples/kobun.txt
```

```
今は昔、竹取の翁といふものありけり。
  いふ  動詞  四段-ハ行 連体形
  あり  動詞・非自立可能  ラ行変格 連用形
  けり  助動詞  助動詞-ケリ 終止形  過去 (伝え聞いた過去)・詠嘆「〜た・〜たそうだ・〜たなあ」
  →  今は昔、竹取の老人というものあった。

秋来ぬと目にはさやかに見えねども風の音にぞおどろかれぬる
  →  秋来たと目にははっきりと見えないけれども風の音にはっと気づかれた
     係り結び: 係助詞「ぞ」(強意) → 結びの「ぬる」は連体形
```

* 品詞分解（`-w` で出さない）: 品詞、活用の種類と活用形、基本形（古文の綴り）、助動詞の意味（学校文法の名前）、
  係助詞と結び、重要古語。中古和文UniDic は語彙素を現代の形で持つ（いふ → 言う、白し → 白い）ので、それを現代語の
  見出しに使います。助動詞は意味ごとに分かれている（なり-断定 / なり-伝聞、たり-完了 / たり-断定）。
* 現代語への組み立て直し（`dragoman/kobun/modernize.py`）:
  * 文節（自立語 + 助動詞・助詞）ごとに、助動詞の連なりの意味を順に現代語の形にする: 受身・使役（笑はる → 笑われる）、
    打消（ず → ない）、存続（たり・り → ている。体言の前と文末）、完了 + 過去（にけり → てしまった）、過去（き・けり → た）、
    推量（む → だろう。「と / とて」の前は意志 → よう）、現在推量（らむ → ているだろう）、過去推量（けむ → ただろう）、
    伝聞（なり → そうだ。体言の前は「という」）、断定（なり → である）など。動詞の活用は共通部分の日本語の活用
    （core/japanese.py）に、現代語の辞書に無い動詞は五段として規則で。
  * 連用形 + ゆく・くる → 「〜ていく・〜てくる」（なりゆく → なっていく）、形容詞の連用形 + 用言 → 「〜く」（白くなる）。
  * 助詞: 述語の前の「の」→「が」（雲の細くたなびきたる → 雲が細くたなびいている）、已然形 + ば →「ので」、
    未然形 + ば →「なら」、ど・ども →「けれども」、にて →「で」、とて →「と言って」、係助詞 ぞ・なむ は訳に出さない。
  * 体言は現代仮名遣いに（やうやう → ようよう）。重要古語は現代語訳に（`dragoman/kobun/grammar.py` の表: をかし → 趣深い、
    いと → とても、あまた → たくさん、たまふ → なさる …）。〜にあらず →「〜ではない」。
* 係り結び: 係助詞 ぞ・なむ・や・か（→ 連体形）、こそ（→ 已然形）と、句点までの最後の述語の活用形を照らし合わせて注を出す
  （合わなければ「結びの流れ・消滅か」）。
* 音読（`-s`）は macOS の say の日本語音声 Kyoko に、現代仮名遣いの読みを渡す（いふ → いう）。
* 助動詞の意味を文脈で選び、品詞分解に「→ ここでは〜」と出す:
  * る・らる: 前に「人 + に」があれば受身、打消が続けば可能（物も言はれず → 物も言うことができない）、心情・知覚の動詞なら
    自発（思ひ出でらる → 自然と思い出す）、身分の高い主語なら尊敬（帝、笑はれけり → 帝、笑いなさった）、ほかは受身。
  * む: 連体形 + 体言は婉曲（思はむ子 → 思うような子）、連体形 + 助詞は仮定・婉曲（〜ようなこと）、「と・とて」の前や
    一人称の主語なら意志（我、京へ行かむ → 我、京へ行こう）、こそ〜め は適当・勧誘（〜のがよい）、ほかは推量。
  * べし: 打消と組めば不可能（べからず → 〜ことができない）、一人称なら意志（つもりだ）、体言の前は当然（はずの）。
  * ぬ・つ + む・べし（てむ・なむ・ぬべし）は強意「きっと〜」。
* 敬語（`dragoman/kobun/grammar.py` の HONORIFICS。中古和文UniDic は「給う-尊敬」と「給える-謙譲」を分けて持つ）:
  * 尊敬語（たまふ・おぼす・のたまふ・おはす・御覧ず …）、謙譲語（たてまつる・申す・参る・聞こゆ・下二段のたまふ …）、
    丁寧語（侍り・候ふ の補助動詞）を見分け、誰への敬意かを注に出す。謙譲語 + 尊敬語は二方面への敬語、
    す・さす・しむ + たまふ は最高敬語（言はせたまふ → 言いなさる。使役ではない）。
  * 現代語: 補助動詞の たまふ →「〜なさる」、たてまつる →「〜申し上げる」、侍り →「〜ます」（思ひ知りはべりぬ →
    思い知りました）、御覧ず →「ご覧になる」、おぼす →「お思いになる」。
  * 主語の手がかり: 尊敬語があって主語が書かれていなければ「身分の高い人 (場面の貴人) の動作」と注を出す。
* 訳を自然にする細かい規則: 助詞の無い主語に「が」（昔、男ありけり → 昔、男がいた）、人が主語の「あり」は「いる」、
  ずして →「ないで」、つつ →「連用形 + ながら」、複合動詞（思ひ出づ → 思い出す）、読点の前の体言は主題（主語の候補）。
* 重要古語は約220語（形容詞は現代の形容詞にして活用させる。しか・さ・て のような、ふつうの語と紛れやすい短い語は入れない）。
* まだ: 誰の動作かの特定（敬語の向きと登場人物の対応）、和歌の修辞（掛詞・縁語・枕詞）、近代の文語文（近代文語UniDic）。
