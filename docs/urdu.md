# ウルドゥー語（作りかけ）

ウルドゥー語はヒンディー語と文法・日常語が同じで、違いは文字（ペルシア文字のナスタアリーク体。短母音を書かない）と
改まった語彙（ペルシア語・アラビア語から）です。そこで、ウルドゥー文字の語をヒンディー語の語形（デーヴァナーガリー）に
引き当て、ヒンディー語の解析器（[docs/hindi.md](hindi.md)）で解析し、表示をウルドゥー文字に戻します。

```
cd ~/.local/share/dragoman-data/ur
curl -L -o kaikki-Urdu.jsonl.gz "https://kaikki.org/dictionary/Urdu/kaikki.org-dictionary-Urdu.jsonl.gz"
cd - && python3 tools/build_hindi_dic.py && python3 tools/build_urdu_dic.py   # → ~/.local/share/dragoman-data/ur/urdu.sqlite
python3 tools/samples.py --lang=ur
python3 dragoman.py --lang=ur samples/urdu.txt
```

```
لڑکے نے کتاب پڑھی۔   (laṛke ne kitāb paṛhī.)
  →  少年,息子が / 本を / 読んだ,学んだ
میرے پاس ایک نئی کتاب ہے۔   (mere pās ek naī kitāb hai.)
  →  {私}〜のところに / {新しい}本が / ある
```

* 引き当て（`urdu/dictionary.py`）: Wiktionary のウルドゥー語の項目（変化表の形）に「ヒンディー語の綴り」があればそれ、
  無ければ「綴りの骨組み」の合うヒンディー語の語形（約20万形と機能語の表）。骨組みは短母音を落とし、ウルドゥー文字の
  書き分け（ز ذ ض ظ → z、س ص ث → s、ت ط → t）とヌクタの無いヒンディー語の綴り（जबान / zabān）をまとめ、重ねた子音を
  1つにし、語末の短い i・u（शांति / شانتی）と語末の ے（e）/ ی（ī）を書き分けたもの（`urdu/script.py`）。Wiktionary の
  ヒンディー語の見出し語に付いたウルドゥー語の綴りとの一致は約90%。
* 候補が複数あれば（میں は मैं「私」と में「〜で」、یہ は यह と ये）、ヒンディー語の解析器が文脈で選びます（前に名詞の
  無い後置詞は選ばない、文頭の「または」は選ばない）。助動詞・機能語の候補を先に並べます（ہے は है）。
* 転写は選んだヒンディー語の語形から作ります（短母音を書かないウルドゥー文字からは作れない）。
* 音読は espeak-ng のウルドゥー語音声。
* 評価用に UD Urdu-UDTB（CC BY-NC-SA 4.0）の test を `~/.local/share/dragoman-data/ur/ud/` に置き、
  `python3 tools/ud_eval.py --lang=ur` で測ります（ヒンディー語と同じく格は測らない）。

| UD Urdu | 形容詞→名詞 | 属格→名詞 | 述語の検出 | 主語 | 目的語 |
|---|---|---|---|---|---|
| UDTB（約1.3万語） | 21.6% | 36.4% | 84.6% | 39.1% | 31.8% |

* ヒンディー語の語形に引き当てられる語は約84%。残りの多くは、ヒンディー語の辞書に無いペルシア語・アラビア語由来の語
  （ریاستی「州の」、مطالبہ「要求」、اقدامات「措置」）と固有名詞です。
* まだ: ヒンディー語に無いウルドゥー語の語を Wiktionary のウルドゥー語の項目から直接引く、izāfat（ペルシア語式の連語:
  وزیرِ اعظم）、ウルドゥー文字のまま転写する（辞書に無い語）。
